## How I work

- **Evidence before trust.** I build an evaluation harness before launch, trace every agent step and keep runs reproducible.
- **Cost is a design input.** I track quality, latency and cost per request from the first version.
- **Access is part of the design.** Each agent acts only within the tenant and permissions of the person it serves.
- **Decisions are written down.** I record trade-offs so the next person can challenge them.
- **Test the certain, evaluate the uncertain.** Deterministic code gets tests and model behaviour gets evals.
- **Blockers surface the same day** with a proposed fix attached.

## How I learn

- I build the smallest working version, then measure it.
- I stay on one topic until it ships in a repo.
- I write up what I measured, including what failed.
- I read primary documentation before tutorials.
